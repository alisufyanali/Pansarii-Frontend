## 🎯 About

Pansari Inn is a modern e-commerce platform specializing in authentic herbal oils, natural remedies, and organic wellness products. Built with cutting-edge web technologies, it offers a seamless shopping experience across all devices with features like video product demonstrations, real-time cart management, and advanced product filtering.

### ✨ Highlights

- 🎥 **Video Product Showcases** - Auto-playing product demonstration videos
- 📱 **Fully Responsive** - Optimized for mobile, tablet, desktop, and 4K displays
- 🛒 **Smart Cart System** - Real-time cart updates with persistent storage
- ❤️ **Wishlist Management** - Save favorite products with login integration
- 🔍 **Advanced Filtering** - Multi-parameter product search and filtering
- 🌐 **Bilingual Support** - English and Urdu language support
- ⚡ **Performance Optimized** - Fast loading with image optimization and lazy loading
- 🎨 **Modern UI/UX** - Clean design with smooth animations and transitions

## 🛠️ Tech Stack

### Frontend

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** React Components (Custom)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Notifications:** [React Toastify](https://fkhadra.github.io/react-toastify/)

### State Management

- **Global State:** React Context API
- **Local Storage:** Browser localStorage for cart/wishlist persistence

### Development Tools

- **Package Manager:** npm/yarn
- **Linting:** ESLint
- **Formatting:** Prettier (recommended)
